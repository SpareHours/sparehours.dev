# Spare Hours website

This repository contains the public website for [sparehours.dev](https://sparehours.dev), hosted with GitHub Pages.

## Pages

- `/` - Spare Hours homepage
- `/field-notes/` - Field Notes Watch Face
- `/field-notes/support/` - Field Notes support
- `/tiny-world/` - Tiny World Watch Face
- `/tiny-world/support/` - Tiny World support
- `/privacy/` - shared Spare Hours privacy policy
- `/field-notes/privacy/` - compatibility redirect to the shared privacy policy
- `/404.html` - custom not-found page

## Local preview

Serve the repository root with any static HTTP server. For example, if Python is installed:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

The site uses plain HTML and CSS. There are no dependencies and no build process.
